# exemplo_gps

A new Flutter project.

## Instalação e Configuração da Biblioteca GeoLocator

acesse pub.dev

**Ler Documentação da biblioteca a ser utilizada**

- geolocator

Como usar:
1. Instalar a biblioteca no projeto -> flutter pub add geolocator
2. Habilitar o uso do geolocator no AndroidManifest.xml (android/app/src/main)
3. Usar a Biblioteca

> obs: antes do primeiro uso do gps, é necessário habilitar o serviço de gps pelo apk (fazer usando código)
